# Battle-Bots

Steps for BattleBots

1. Connect to QUBRobots Wifi on your device (Ask committee for password)
2. Download script
3. Open terminal
4. Run 'python bb_controller.py [num]' - replace [num] with your bot number e.g 'python bb_controller.py 1' for bot 1
5. Control bot using arrow keys, WASD or clicking on arrow icons
6. Have fun with your battle bot!
