# Battle-Bots

Steps for BattleBots

1. Connect to QUBRobots Wifi on your device (Ask committee for password)
2. Download script
     (And python if you don't already - python.org)
4. Open terminal
5. Run 'python bb_controller.py [num]' - replace [num] with your bot number e.g 'python bb_controller.py 1' for bot 1
6. Control bot using arrow keys, WASD or clicking on arrow icons
7. Have fun with your battle bot!
